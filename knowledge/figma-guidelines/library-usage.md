# Using the HPE Design System Libraries

When creating a UI in Figma:

- **Use existing components.** Build with components from the HPE Design System
  libraries. Do not invent or recreate components that are not in the
  libraries.
- **Keep components as designed.** Do not change the design of existing
  components. Use their available variants and properties.
- **Start with the App container.** Use the App container from the library as
  the starting point for every page, then build the page within it.
- **Bind variables to values.** Apply the appropriate library variable to
  every design value. Do not leave those values unbound or replace them with manually entered values.
