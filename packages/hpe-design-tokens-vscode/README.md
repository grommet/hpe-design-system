# HPE Design Token Resolver for VS Code

Hover a supported Grommet t-shirt size to see its resolved HPE Design Token value.

The initial release supports Grommet `gap`, `margin`, `pad`, and `borderWidth` values, including nested `pad` and `margin` values. It also resolves HPE CSS custom properties, such as `--hpe-spacing-medium`. Its compact bundled manifest is generated from the released HPE dimension tokens.
